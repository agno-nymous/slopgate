2 of 5: How it works

How a review works

  1. 1

    Find changed functions

    Slopgate lists the Python functions that the pull request adds or changes.

  2. 2

    Name the problem

    Ruff, vulture, and syntax-tree checks label long if/elif chains, dead code, and deep nesting. To find a copy of an existing function, Slopgate matches its words against the repository, and Nemotron Super judges the close matches.

Steps 3 to 5 run in a Nebius ConTree sandbox

  1. 3

    Write tests for the old code

    Nemotron Super writes tests that record what the old code does. The tests must pass on the old code.

  2. 4

    Rewrite

    Nemotron Super rewrites the function. If the rewrite fails, Nemotron Ultra tries once more.

  3. 5

    Check

    The rewrite must pass those tests and the repository's own tests. If it fails, the pull request gets a comment and no code change.

  1. 6

    Post

    A rewrite that passes appears as a suggested change on the pull request. You decide whether to merge it.
