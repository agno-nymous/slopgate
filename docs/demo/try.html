5 of 5: Try it

Try Slopgate

Paste a Python function and your Nebius Token Factory key. The page asks Nemotron Super for a rewrite and for tests, then runs both versions in your browser. The key stays in this tab and goes only to Token Factory.

Run it on your repository

  1. Install uv, and get your keys from Nebius Token Factory.
  2. Set the keys in your shell. Slopgate sends them to Nebius only.
    export NEBIUS_API_KEY=... NEBIUS_PROJECT_ID=...
  3. Clone the repository and check out the branch you want to review. Then review its last commit. A dry run posts nothing to GitHub.
    uvx --from git+https://github.com/agno-nymous/slopgate slopgate review --repo . --base HEAD~1 --head HEAD --dry-run
  4. To review one pull request, use --pr <number> --dry-run instead of --base and --head.
  5. The README has the full steps and the cost of one review.

One review cost $0.045 to $0.103 in Token Factory tokens in the 4 recorded reviews.
