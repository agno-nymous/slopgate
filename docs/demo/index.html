Slopgate fixes the AI slop that coding agents write in Python.

It runs on each GitHub pull request. It finds long if/elif chains, unreachable code, and deep nesting. Nemotron models on Nebius Token Factory rewrite them. Slopgate posts a rewrite only when tests pass on the old code and on the new code. The whole benchmark below cost $1.16.
